REFTECH — AI-Powered Video Assistant Referee ⚽

AI PROJECT

An automated VAR system combining player and ball tracking with computer vision to analyze refereeing decisions in real time. It uses YOLOv8 for object detection and DeepSORT for tracking across video frames, draws a preliminary offside line, and saves the processed video automatically. The goal: reduce human error and speed up decision-making, built on Google Colab with free GPU acceleration, with room to scale on datasets like SoccerNet.

    out = cv2.VideoWriter(output_path, fourcc, fps, (width, height))

    while cap.isOpened():
        ret, frame = cap.read()

        results = model(frame)                      # YOLOv8 inference
        boxes = results[0].boxes.xyxy.cpu().numpy()
        confidences = results[0].boxes.conf.cpu().numpy()

        for i, box in enumerate(boxes):

            cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)

ATM PIN Login System

DEV

A C++ console program that validates a user's PIN with a limited number of tries, counting down attempts, changing the console color on success or failure, and locking the card out after 3 wrong entries.

atm_login.cppC++
bool Login() {
    string PinCode;
    int Counter = 3;
    do {
        Counter--;
        PinCode = ReadPinCode();
        if (PinCode == "1234") {
            return 1;
        } else {
            cout << "\nWrong PIN\n";
            system("color 4F");  // red on failure
        }
    } while (Counter >= 1 && PinCode != "1234");
    return 0;
}
